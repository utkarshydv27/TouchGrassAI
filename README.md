

\# TouchGrass AI 🌿



\*\*Less scrolling. More living.\*\*



TouchGrass AI is a local-AI-powered web app that helps people spend more time outdoors through personalized nature missions.



\## Features



\- Generate outdoor missions for 15, 30, or 60 minutes.

\- Choose nature exploration, walking, birdwatching, or gardening.

\- Select an experience level.

\- Use a locally running Ollama model for AI generation.

\- Track completed missions in browser local storage.



\## Tech Stack



\- Python and Flask

\- Ollama

\- Qwen 2.5 1.5B model

\- HTML, CSS, and JavaScript

\- Pytest



\## Requirements



\- Windows, macOS, or Linux

\- Python 3.13 (or a compatible Python version)

\- Ollama installed

\- Sufficient RAM and disk space for the selected model



\## Setup



1\. Install Ollama from https://ollama.com/download

2\. Download the model:



&#x20;  ```bash

&#x20;  ollama pull qwen2.5:1.5b

&#x20;  ```



3\. Create and activate a Python virtual environment.

4\. Install dependencies:



&#x20;  ```bash

&#x20;  pip install -r requirements.txt

&#x20;  ```



5\. Start the application:



&#x20;  ```bash

&#x20;  python app.py

&#x20;  ```



6\. Open http://127.0.0.1:5000



Keep Ollama running while generating missions.



\## Run Tests



```bash

python -m pytest -v

```



\## Privacy and Open Innovation



AI requests are sent to the locally running Ollama service rather than a hosted AI API. This can keep mission prompts on the user's computer and allows compatible local models to be changed.



After the model and dependencies have been installed, mission generation can work without internet access, provided the local Ollama service is available.



Progress is stored in browser local storage. It is not GPS-verified, and the app does not currently identify the user's actual location.



\## Limitations



\- Outdoor suggestions are generated by an AI model and may need human judgment.

\- Location-specific, weather, and real-time safety information are not currently provided.

\- A working Ollama installation and downloaded model are required.
